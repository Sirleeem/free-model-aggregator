One server, two APIs: an OpenAI- and Anthropic-compatible aggregator that routes each request to the best free model across ten providers, translating between the OpenAI, Anthropic and Gemini wires, streaming in the wire the client used, and failing over when a provider's free tier refuses.

## Run it

```sh
node main.ts
```
